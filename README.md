# lesson06-dp

《人工智能程序设计与实践》第 6 次课（10/23）作业 —— 贪心与动态规划。
每次作业独立建仓，本仓库只放本次内容。

## 文件

| 文件 | 内容 |
| --- | --- |
| `coin.py` | Step1 凑硬币：贪心 vs 动规（面额 [1,5,11]，目标 15） |
| `knapsack.py` | Step2 0-1 背包（1000g，回溯组合）＋预算 800 对比＋必投项目约束 |
| `research.py` | 独立研究三题：n-后回溯、完全背包改一行、分支限界结点数对比 |
| `progress.md` | 进度报告（检查点、问题、自查、研究、AI 使用记录） |

## 运行

```bash
python coin.py        # 贪心 5 枚 vs 动规 3 枚
python knapsack.py    # 315，睡袋+食物+水具；800g -> 255；必投帐篷 -> 300
python research.py    # n-后解数、完全背包 360、分支限界 23 结点
```

## 检查点

- 凑硬币：贪心 5 枚（11+1+1+1+1），动规 3 枚（5+5+5）
- 背包：最优重要度 315，组合 睡袋 + 食物 + 水具（350+400+250=1000g）

背包统一用「至多装满」变体（容量可以不花完，dp 初始化为 0）。
指南表格的「重要度」列为空，取值见 `knapsack.py` 的 `ITEMS`（三项合计 315）。
